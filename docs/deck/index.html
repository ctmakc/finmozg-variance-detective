5 How Zetaris and Meterless are used

Zetaris is the only door to the data

  • 5 sources registered by script; agents query only POST /sql-editor/sqls/run
  • finance_usl: 9 business tables, PK/FK, activated from raw sources, BoC rate joined on invoice date
  • RUN DQ: PK rule flags MRP-88213 (31 records, 2 invalid) before any agent asks
  • Investigators write Spark SQL and repair it from Zetaris error messages

Meterless is memory, shared state and power

  • H-MEM: schema map (warm run skips discovery), confirmed findings, Skeptic rulings, audit ledger
  • World Model: one evidence graph for 10+ agents, provenance per write
  • Markovian: Skeptic reviews evidence rows in bounded chunks with carryover
  • Runtime: every model call app → Meterless → Nemotron, signed receipt per call
